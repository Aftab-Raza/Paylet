# Paylet application design

Approved direction: precise ledger interfaces inspired by the landing page.

- Light page #FFFFFF with #091413 text.
- Dark page #000000, charcoal #121212 / #202020 surfaces, white text, #A0A0A0 secondary text and #505050 borders.
- Raised surfaces and quiet borders belong to the same neutral ramp.
- Blue marks primary actions, green confirms success, red marks destructive actions.
- Be Vietnam Pro is the existing product typeface.
- Amounts align consistently with tabular numerals.
- Controls retain comfortable tap targets at narrow widths.
- The mobile dashboard header uses logo, notifications, theme switch and a compact menu on one row. The menu contains page links with small icons, without Overview or another theme switch.
- Other app pages use compact Back, Forward and theme controls. Forward follows app history and is disabled when unavailable; direct links keep a parent-page fallback.
- Money filters and refresh controls share a compact row where space permits.
- Popups use the existing focus-managed Modal and brief opacity/translation feedback.
- Reduced-motion mode exposes the final state immediately.
- Notifications use one status icon, short copy, close control and three-second progress.
- Records, privacy choices and consent language come from the existing product.
- Unslop method credit: Damir Sokolovsky (@heydamir), CC BY 4.0, https://heydamir.design/unslop.

- Landing dark mode uses midnight black #080B10, white, and lime #C8FF39 accents (visual balance roughly 60/30/10). Major dark-mode sections alternate black and white.
- The landing hero follows the supplied centered Better Stack reference composition: large centered headline and actions, with restrained dotted side ribbons and expense-to-people trails. The money animation ends after three cycles and is disabled for reduced motion. The About section explains who owes whom.
- Landing copyright: © 2026 Raza.co. All rights reserved.

- Groups use the landing midnight/white/lime palette with solid, restrained surfaces. The directory defaults to compact rows; group pages show per-currency ledger balances, named member previews, bills, and collapsed member/settings tools. Existing permissions and payment confirmation rules remain authoritative.

Groups direction: shared-money records for friends; calm, exact, accountable; the visual world is a shared ledger. Current balances and recognizable members carry the emphasis. The signature is a clear “You owe / To receive” label beside each currency amount.
